# 딱코스트 마트

`dist/index.html`을 브라우저로 열면 플레이할 수 있는 정적 웹게임입니다. 외부 폰트가 없어도 시스템 글꼴로 동작합니다.

- 90초, 4×4 상품판, 12종 상품
- 선택 상품의 가격 합계가 목표와 같으면 계산 성공
- 상품당 10점 × 콤보 배수, 5초 이내 연속 성공 시 최대 5배
- 오답 3초 차감, 최고 점수와 소리 설정은 현재 브라우저에 저장
- 목표는 현재 보드의 서로 다른 2~4개 상품으로 생성하여 항상 해결 가능
- 탭을 벗어나도 시간은 흐릅니다.
- 게임 방법 설명 창을 여는 동안 게임·콤보 시간이 일시 정지됩니다.
- 오리지널 BGM과 효과음은 각각 켜고 끌 수 있습니다.

외부 라이브러리나 빌드 과정 없이 실행됩니다. 효과음은 Web Audio, 상품은 운영체제의 이모지입니다.

## 검증

Node.js가 설치된 환경에서 프로젝트 폴더에서 `node check-game.cjs`를 실행합니다.

`dist/`에는 실행에 필요한 HTML, CSS, JavaScript가 모두 들어 있습니다. 개인 호스팅 설정과 로컬 미리보기 이미지는 Git 업로드 대상에서 제외합니다.
